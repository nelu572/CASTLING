# Notion 안내 갱신

사용자가 `노션 안내 갱신해`, `Notion 가이드 갱신`, `기획서 색인 업데이트`처럼 Notion 문서 구조를 로컬 안내서에 반영해 달라고 명시적으로 요청했을 때만 사용한다.

## 목적과 범위

- 갱신 대상은 [NOTION_GUIDE.md](../notion/NOTION_GUIDE.md)뿐이다.
- Notion 원본 페이지를 수정·추가·삭제하지 않는다.
- 게임 코드, 씬, 에셋, 다른 문서는 변경하지 않는다.

## 절차

1. 현재 `NOTION_GUIDE.md`와 기준 Notion 루트 페이지를 확인한다.
2. 루트에서 문서 구조, 페이지 제목, 상위·하위 관계, 직접 연결된 문서의 용도를 다시 조사한다.
3. 기존 안내서와 비교해 빠진 페이지, 이름 변경, 이동, 삭제된 링크, 문서 역할 변화를 찾는다.
4. 필요한 범위에서만 빠른 선택과 문서 구조를 갱신한다. 세부 기획 내용을 대량으로 복사하거나 요약하지 않는다.
5. 링크가 대상 페이지를 가리키는지 확인하고, 갱신한 항목과 유지한 항목을 요약한다.

## 확인이 필요한 경우

- 페이지의 역할이나 구조가 모호해 안내서 분류를 정하기 어려울 때
- 기존 색인에 없던 문서를 어떤 항목으로 노출할지 결정해야 할 때
- 현재 안내서와 Notion 원문이 기획 의미상 충돌할 때

위 경우에는 임의로 분류하지 말고 사용자에게 질문한다.
