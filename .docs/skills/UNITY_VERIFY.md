# Unity 변경 검증

변경 범위에 맞춰 다음을 확인하고, 실행하지 못한 항목은 이유를 남긴다.

1. `git diff --check`로 공백 오류를 확인한다.
2. `git status --short`로 의도하지 않은 생성물이 없는지 확인한다.
3. `Assets/`에서 새로 만들거나 이동한 항목은 `.meta` 파일이 함께 있는지 확인한다.
4. C# 변경 후 Unity Editor Console에 컴파일 오류가 없는지 확인한다.
5. 씬·프리팹 변경 후 해당 에셋을 열어 누락된 참조와 컴포넌트 경고를 확인한다.
6. 조작·물리·CASTLING처럼 플레이에 영향을 주는 변경은 관련 개발 씬에서 Play Mode로 확인한다.
