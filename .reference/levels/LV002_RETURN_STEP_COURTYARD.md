## 핵심 아이디어와 공간

아래 사람이 첫 접근을 만들고, 위 사람은 남은 사람이 올라올 길을 물체로 남긴다. 처음의 받침 역할과 이후의 공급·배치 역할이 바뀌면서 두 사람이 같은 높은 면에 합류한다.

공허가 없는 낮은 안뜰 오른쪽에 높은 면이 있고 그 위에 물리 발판이 놓인다. 상부 물체를 왼쪽으로 내려보내 하부의 도약면으로 바꾸는 구조다. 물체는 `Level_B/Grid/Room_01/Puzzles/PushablePlatform_B`에서 찾는다. 낙하·재배치 공간, 물체의 반대편에 접근하는 자리, 상부 착지 여백을 함께 유지한다.

## 실제로 통과한 기본 해법

1. 둘이 높은 면 아래로 접근한다. 킹이 받침이 되고 룩이 킹을 밟아 상부로 오른다.
2. 룩이 상부 물리 발판을 뛰어넘어 오른쪽으로 간 뒤 **왼쪽으로 민다**. 물체 전체가 높은 면 가장자리를 벗어나 하부 안뜰로 내려온다.
3. 킹이 내려온 발판을 오른쪽 벽 가까이 밀어 도약면으로 만든다. 룩은 킹이 올라올 상부 착지 자리를 비운다.
4. 킹이 발판을 밟고 높은 면으로 올라 합류한다. 둘이 오른쪽의 작은 턱을 넘어 다음 연결면에 접지한다.

이 경로는 CASTLING·룩 수평 이동 능력을 사용하지 않고 통과한 사례다. 두 사람이 연결면에 도달한 것이 확인 범위이며 챕터 완료를 뜻하지 않는다.

| 구간 | 킹의 기여 | 룩의 기여 |
| --- | --- | --- |
| 첫 접근 | 몸체로 상부 진입을 받쳐 줌 | 받침을 이용해 상부 확보 |
| 발판 공급 | 낙하를 보고 접근·재배치할 자리 판단 | 물체 반대편 진입, 아래로 물체 공급 |
| 합류 | 물체를 도약면으로 배치하고 등반 | 상부 착지 여백 확보·공동 전진 |

## 대안·실패·복구

| 경로·상황 | 내용과 확인 수준 |
| --- | --- |
| 점프 중 CASTLING | 물체 없이 둘 다 상부로 올라가는 공동 단축 후보. 미실행이며 물체 풀이보다 편하고 직관적인지 비교해야 한다. 발판 필수 퍼즐로 설명하지 않는다. |
| 공급 담당 반전 | 상부로 간 킹이 물체를 내리거나, 공급한 사람도 함께 내려와 둘이 같은 발판으로 올라가는 안은 설계상 허용 후보이며 미검증이다. |
| 받침·도약 실패 | 닫힌 안뜰 바닥에서 다시 접근하는 구상. 모든 실패 상태의 복구를 검증하지 않았다. |
| 하부 왼끝으로 간 물체 | 반대편 왼면에 접근해 오른쪽으로 밀고 벽 가까운 도약면으로 사용하는 별도 사례에서 5조건을 통과했다. 시작 위치를 따로 배치한 국소 복구 검사이며 저장 시작 연속 완주와 구분한다. |
| 그 밖의 물체 상태 | 상부 오른끝 역밀기, 점프 충돌로 턱 너머 밀기, 낙하 물체와 캐릭터 충돌은 미검증이다. 물체가 모든 위치에서 복구된다고 보장하지 않는다. |
| 메뉴·낙사 재시도 | [VoidRespawnZone](../../Assets/Scripts/Gameplay/VoidRespawnZone.cs)은 캐릭터를 Entry로 복귀시킨다. 물리 발판을 초기 배치로 복원하지 않으므로 재시도를 상자 초기화로 안내하지 않는다. |

## 평가·검증 한계와 다음 질문

- 사용자 평가: 나쁘지 않지만 상자를 처음 소개하기에는 부적절하며, 상자를 이미 경험한 뒤의 응용 후보로 보존한다. 배치 챕터·순서는 미정이다.
- 2026-10-19 통합 저장본의 연속 PlayerInput 검사에서 상부 진입·물체 공급·두 사람의 연결면 도달과 접지를 포함한 9조건을 통과했다. 경로 중 몸체 위치를 직접 쓰지 않았다. 기준 에셋은 보관 씬 추가 커밋 `fce3d66`에 포함돼 있다.
- 2026-10-20 현행 조작으로 현재 보관 씬의 저장 Entry부터 실제 PlayerInput 구간을 이어 기본 해법을 재확인했다. 킹 받침·룩 상부 진입, 물체의 반대편 접근과 하부 공급, 킹의 벽 옆 재배치·등반, 마지막 턱과 양쪽 연결면 접지를 확인했다. CASTLING·룩 직선 이동을 사용하지 않았고 경로 중 위치·속도를 직접 쓰거나 씬·물리·장치를 변경하지 않았다. Console 오류·경고 없음과 Stop 뒤 입력 자원 복원을 확인했으며, 모든 물체 끝상태·우회·실패 복구를 재검증한 것은 아니다.
- 별도 B 제작 씬에서 하부 물체 복구 사례를 확인했지만, 그 결과가 통합 씬의 모든 물체 끝상태를 확인한 것은 아니다. 현재 에셋으로 사용 전 필요한 상태를 다시 확인한다.
- 초기 단독 상부 진입, 모든 물체 끝상태, 점프 중 CASTLING, 사람 둘의 첫 발견성·운반·대기 체감은 미검증이다. 카메라에서 아래 사람·위 사람·물체와 낙하 자리가 함께 읽히는지도 확인한다.
- 다음 검토: **물체를 내려 길을 남기는 협동이 점프 CASTLING보다 선택할 만한가?** 더 편한 길로 같은 경험을 얻는다면 숨은 능력 제한을 추가하기 전에 물체 경로의 의미를 다시 검토한다.

씬이나 물체·몸체·조작이 바뀌면 해법과 복구의 확인 상태를 갱신한다. 일회성 원자료의 정리 이후에도 위 해법·평가 이유·검증 한계는 카드에 보존한다.
