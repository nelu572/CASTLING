## 핵심 아이디어와 공간

한 사람이 먼저 만든 위치가 상대의 진입을 열고, CASTLING 뒤에는 담당하던 길까지 넘겨받는다. 킹은 상부 위치를 확보한 뒤 아래에서 룩의 진행을 지원하고, 룩은 아래 진입을 맡은 뒤 상부 진행으로 역할을 바꾼다.

왼쪽 첫 틈을 지나면 중앙 질량의 위·아래 회랑이 갈라지고 오른쪽 공동면에서 합류한다. 상부 판 A는 하부 문 A를, 하부 판 B는 상부 문 B를 연다. 아래 첫 입구와 위 후반의 낮은 통로, 교환할 때 두 몸체를 받을 수 있는 열린 면이 핵심 공간이다. 판 이름 A/B는 이 레벨 내부의 장치 구분이다.

## 실제로 통과한 기본 해법

1. 둘이 첫 틈을 넘는다. 킹은 돌출면을 거쳐 중앙 질량 위로 오르고 룩은 낮은 아래 입구로 접근한다.
2. 킹이 **상부 판 A**를 밟아 **하부 문 A**를 연다. 룩은 문 A를 지나 **하부 판 B**로 간다.
3. 킹은 상부 A, 룩은 하부 B 쪽 열린 면에 정렬한다. CASTLING을 홀드해 킹은 아래 B, 룩은 위 A로 교환한다.
4. 킹이 **판 B를 유지**하는 동안 룩이 **상부 문 B**를 완전히 지나 낮은 통로로 전진한다. 킹은 상대의 통과를 확인한 뒤 출발한다.
5. 확인한 경로에서는 룩이 수평 이동 능력으로 오른쪽 공동면에 도달했고 킹은 하부 계단을 올라 합류했다. 두 사람이 공동면에 접지한 상태를 경로 끝으로 확인했으며 챕터 완료를 뜻하지 않는다.

| 구간 | 킹의 기여 | 룩의 기여 |
| --- | --- | --- |
| 교환 전 | 상부 점프·위치 확보, 아래 진입 개방 | 아래 통로 진입, 상부 진행을 열 판 B 확보 |
| 교환 직후 | 아래에서 판 B 유지, 출발 시점 판단 | 위 문 통과·낮은 통로 진행 |
| 합류 | 하부에서 상승·공동면 확보 | 상부에서 오른쪽 공동면 도달 |

## 대안·실패·복구

| 경로·상황 | 내용과 확인 수준 |
| --- | --- |
| 수평 이동 능력 대신 일반 이동 | 후반의 계단을 함께 쓰는 설계상 허용 후보. 기본 완주와 별도로 입력 검증하지 않았다. 능력 사용이 필수라고 평가하지 않는다. |
| 교환 위치·담당 변경 | 판 B 직전 조기 교환, 후반 추가 CASTLING은 미검증 후보다. 교환 뒤에도 양쪽의 행동과 합류가 남는지 확인한다. |
| 우회 검토 | 시작 역할 역순, 문 안 몸체 점유를 이용한 인계, 공중 교환, 한 명 선행 후 운송·천장 접근은 미검증이다. 전부 차단됐다고 단정하지 않는다. |
| 상부 점프 실패 | 아래 바닥에서 왼쪽 돌출면으로 돌아와 재등반하는 구상. 별도 실제 입력 복구 검사는 없다. |
| CASTLING 취소·안전 실패 | 열린 면에 다시 정렬해 홀드 재시도하는 예상 복구다. 현재 안전 판정과 실패 표현을 사용하며 이 카드에서 새 발동 제한을 정하지 않는다. |
| 판 B 조기 해제 | 다시 B를 밟아 문을 열어 주는 예상 복구다. 문 안 몸체 보호를 필수 타이밍 풀이로 삼지 않는다. |
| 첫 틈 낙사 | 기존 공동 복귀 장치가 있다. A의 낙사→복귀 경로는 통합 기본 완주와 별도로 재검증하지 않았다. 새 중간 체크포인트를 채택하지 않았다. |

## 평가·검증 한계와 다음 질문

- 사용자 평가: A는 상당히 좋지만 문·CASTLING을 배우는 첫 구간에는 맞지 않는다. 이 선행 경험 평가는 특정 챕터 배정을 뜻하지 않는다.
- **후반 계단 사이 틈은 몸체보다 좁아 떨어지지 않는다는 사용자 관측**이 있다. 입력 검사에서 점프했다는 사실로 점프 필수·낙하 위협을 주장하지 않는다. 수정 요청 없이 틈을 넓히지 않는다.
- 2026-10-19 통합 저장본의 연속 PlayerInput 검사에서 문 개방·CASTLING 입력·두 사람 합류와 접지를 포함한 7조건을 통과했고, 경로 기록에서 실제 위치 교환도 확인했다. 경로 중 몸체 위치를 직접 쓰지 않았다. 기준 에셋은 보관 씬 추가 커밋 `fce3d66`에 포함돼 있다.
- 2026-10-20 현행 조작으로 현재 보관 씬의 저장 Entry부터 실제 PlayerInput 구간을 이어 기본 해법을 재확인했다. 첫 틈·킹 상부/룩 하부 진입, 두 판과 문 개방, CASTLING 인계, 룩 직선 이동과 킹 계단, 공동면의 양쪽 접지를 확인했다. 경로 중 위치·속도를 직접 쓰거나 씬·물리·장치를 변경하지 않았다. Console 오류·경고 없음과 Stop 뒤 입력 자원 복원을 확인했으며, 미검증 대안·복구 범위를 완료 처리한 것은 아니다.
- 사람 둘의 첫 발견성, 판과 문 관계의 가독성, 대기 체감·재미, 모든 우회와 복구는 확인되지 않았다. 기본 최소 직교 크기 8에서 주요 판단 정보가 함께 읽히는지 다시 본다.
- 다음 검토: 더 단순하고 직관적인 우회가 있는가? 그 경로에서도 양쪽이 준비·판단·진행에 기여하는가? 두 판의 관계를 알아내기 전 한쪽이 오래 대기하는가?
