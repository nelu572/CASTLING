# CASTLING Notion 기획서 안내서

> 기준 페이지: [CASTLING](https://app.notion.com/p/3dcb3e6e776c80bca808c23441091ae6?source=copy_link)
>
> 이 파일은 필요한 기획 문서를 바로 찾기 위한 색인이다. 세부 설정의 원본과 최신 상태는 Notion이며, 이 안내서만으로 세부 내용을 확정하지 않는다.

## 빠른 선택

| 필요 정보 | 먼저 볼 문서 | 범위 |
| --- | --- | --- |
| 게임의 핵심 콘셉트와 협동 구조 | [기획서](https://app.notion.com/p/3dcb3e6e776c81f08abde9fa6cefdb80) | 킹·룩 역할, CASTLING, 물리 퍼즐 방향 |
| 화면 분위기와 캐릭터·플랫폼의 시각 방향 | [아트 레퍼런스](https://app.notion.com/p/3dcb3e6e776c81f2bb63c68f908c5ec5) | 2D 미니멀 화면, 체스 실루엣, 흑백 대비, 배경 레이어 |

## 문서 구조

```text
CASTLING (프로젝트 루트)
├─ 기획서
└─ 아트 레퍼런스
```

## 사용 규칙

1. 먼저 이 안내서에서 필요한 문서를 고른다.
2. 선택한 문서와 직접 연결된 하위 페이지만 읽는다.
3. 관련 없는 문서·하위 페이지는 탐색하지 않는다.
4. Notion의 변경·추가·삭제는 사용자가 명시적으로 요청한 경우에만 수행한다.
5. 이 색인은 Notion 구조가 달라졌거나 사용자가 갱신을 요청한 경우에만 다시 확인한다.
6. 전체 탐색, 대규모 요약, 기획서 정리는 사용자가 명시적으로 요청한 경우에만 수행한다.
7. 구현 요청이 기획서와 충돌하거나 중요한 설계 선택이 필요하면 변경 전에 사용자에게 확인한다.
