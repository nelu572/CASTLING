# 레벨 레퍼런스 분석 자료

[레벨 디자인 절차](../../.codex/skills/LEVEL_DESIGN.md)에서 선택한 작품의 근거를 찾는 자료다. 현재 프로젝트의 기능은 [프로젝트 근거](LEVEL_DESIGN_CONTEXT.md), 개별 요청의 채택/제외 판단은 [설계 양식](../../.templates/LEVEL_DESIGN_TEMPLATE/template.md)과 작업 기록에서 관리한다.

재사용할 관찰만 작품별로 확인일·출처·장면·사실/해석·미확인 범위를 유지한다. 초안은 작업 폴더에서 분석하고 반복 가치가 있을 때 이 파일에 합친다. 다른 작품을 선택하면 필요한 프로필만 읽으며, 확인한 자료가 없는 작품은 이름만으로 분석된 것으로 다루지 않는다. 예를 들어 Celeste를 지정해도 이 파일에 검증된 Celeste 프로필이 있다는 뜻은 아니다. 관련 없는 프로필을 빈칸으로 미리 늘리지 않는다. 출처/판본이 바뀌면 해당 관찰을 재확인하고 오래된 적용 가설을 갱신한다.

## PICO PARK · 일반판

2026-10-15 기존 관찰 기록을 프로젝트 근거 문서에서 옮겼다. 일반판만 다루며 Classic Edition·PICO PARK 2와 섞지 않는다. 이 프로필은 기본 설계 명령이 아니다.

| 근거 수준 | 내용 |
| --- | --- |
| 출처 확인 | [개발사 공식 소개](https://picoparkgame.com/en/pp1/)의 설명을 2026-10-15 확인했다. 2~8인 협동 액션 퍼즐이며 인원에 따라 지형을 조정하고, 열쇠·문·목표와 멀티플레이 기믹을 설명한다. |
| 이미지 관찰 | 2026-10-15 공식 World Mode 이미지 [0](https://picoparkgame.com/pp1/assets/img/mode/world/0.png)·[1](https://picoparkgame.com/pp1/assets/img/mode/world/1.png)·[2](https://picoparkgame.com/pp1/assets/img/mode/world/2.png)·[3](https://picoparkgame.com/pp1/assets/img/mode/world/3.png)을 직접 확인했다. 스테이지 번호·플레이 시간대는 제공되지 않는다. 0은 상부가 열린 양쪽 지면 사이의 틈, 1은 길고 얇은 상부 발판과 아래의 큰 빈 공간, 2는 위아래 지형 사이에 수직선 형태의 요소가 있는 구간, 3은 천장에서 내려온 돌출부와 중간 선반·하부 지면이 보인다. 스크린샷의 색 영역만으로 실제 Collider나 기믹 작동을 확정하지 않는다. |
| 관찰의 해석·적용 | 네 이미지에서 개방된 방향과 지형의 두께가 서로 다르다. 전체를 같은 방 형태로 채우기보다 요구 행동과 공간 분리에 맞춰 큰 실루엣·빈 공간·국소 제한을 고른다는 설계 가설을 검토한다. 2·3의 천장/돌출부가 있는 사례도 함께 비교하므로 모든 레벨을 상부 개방형으로 일반화하지 않는다. 현재 퍼즐에 필요한 지지면·장벽·복구를 먼저 정하고 원작 윤곽·기믹을 복제하지 않는다. |
| 미확인과 갱신 조건 | 전체 게임의 평지/단차 비율·정확한 월드 치수·충돌·점프 정밀도·풀이·기믹 도입 순서·난이도 곡선·카메라 동작은 미확인이다. 이 판단이 필요한 요청에서는 해당 스테이지의 플레이 영상/입력 근거를 추가하고 장면·시간대·관찰 범위를 갱신한다. |
| 적용 범위 | 당시 평지형 협동 테스트에서 선택한 참고 자료다. 현재 요청이 다른 경험이면 해당 요소만 채택하거나 이 프로필을 제외한다. 원작의 평지 비율이나 보편적인 우수성을 확인한 기록이 아니다. |
| 적용 가설 | 목표·장치 상태의 가독성과 시도/복구 관계를 요청 목적에 맞게 검토한다. 현재 사용할 능력·기믹은 프로젝트 분석에서 선택하며 이 작품을 이유로 스위치나 특정 풀이를 의무화하지 않는다. |
| 가져오지 않을 전제 | 2~8인 구성, 인원별 지형 변경, 온라인 연결, 열쇠 수집·신규 기믹을 현재 프로젝트 기능으로 가정하지 않는다. 협동 여부는 CASTLING의 Notion·구현을 근거로 판단한다. |
