# 레벨 디자인 하네스 외부 검토 자료

- 목적: `review/level-design-harness` 브랜치에서 하네스의 구조·검증 범위·한계를 외부 검토자가 독립적으로 읽도록 한다.
- 상태: 문서 검토용 스냅샷. 실제 레벨 제작이나 새로운 Unity 플레이 검증은 수행하지 않는다.
- 파일과 사용 방법: [REPORT.md](REPORT.md)에서 변경 범위·설계 흐름·세 요청의 모의 점검·남은 한계를 읽고, 연결된 저장소 문서를 확인한다.
- 포함 기준: 사용자의 선택적 보고서 포함 요청에 따라 이 폴더의 README와 REPORT 두 Markdown만 Git에 반영한다. `.gitignore` 및 다른 `.work` 자료의 제외 정책은 유지한다.
- 제외 대상: Unity 씬·게임플레이 코드·에셋 변경, 로컬 캡처/로그/임시 코드, 다른 작업 보고서 원본, 인증 정보·개인 경로.
- 보존과 정리: 이 두 문서는 검토 브랜치의 근거로 보존한다. 검토 완료 후 불필요해지면 버전 관리 이력을 남기는 별도 변경으로 정리하며, 로컬 임시 자료 정리 과정에서 삭제하지 않는다.
